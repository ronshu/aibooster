## 3. 사용법

```
/ip-register 25                              ← No 하나
/ip-register 25-27                           ← 범위
/ip-register 25,30                           ← 여러 개
/ip-register 20대 일본 여성                   ← 조합으로 지정 (생성관리에서 No를 찾아 진행)
/ip-register 25 C:\Users\kimsj\Desktop\IP 모델 ← 작업 폴더 지정
```

- 폴더 경로를 생략하면 바탕화면에 `IP 모델` 폴더를 만들어 그 안에서 작업합니다.
- 시작하면 중간에 묻지 않고 보고까지 끝까지 진행합니다.

### 작업 폴더 구성

```
IP 모델\
├─ 294 Seong-min (성민) 183.66.png   ← 원본 (등록번호를 붙여 이름 변경)
├─ 294 Seong-min(성민)\              ← 번호 폴더 (이미지 + 페르소나 엑셀)
├─ @제외\                             ← 제외 이미지 + @중복검수_비교표_No24.jpg
└─ @pipeline\                         ← 진행 기록 (run_24.json, models_24.json)
```

- 모든 파일 작업은 작업 폴더 안에서만 합니다.

## 5. ChatGPT 얼굴 생성 (`ip-generation`)

ChatGPT의 `@ip generation`에 `국적_연령대_성별` 키워드를 넣어 서로 다른 가상 모델 5명을 만듭니다.

- **입력 예:** `스웨덴_20대_여`, `한국_40대_남`
- **새 대화를 시작할 때:** 참조 이미지 `IP모델 소스.png`를 먼저 첨부한 뒤 키워드를 입력합니다.

### 생성 규칙

1. 얼굴·헤어 프롬프트 5개를 먼저 작성합니다. 얼굴형, 골격, 비율, 눈매, 코, 입술, 턱선, 헤어스타일을 서로 확실히 다르게 설계합니다. **같은 얼굴에 헤어만 바꾸는 방식은 금지**입니다.
2. 이미지 생성은 **프롬프트 1개당 1번씩 따로, 총 5번** 호출하고, 매번 1장만 출력합니다.
3. 공통 조건
   - 세로 3:4 비율, 흰 배경, 가슴 위 상반신, 인물 1명
   - 부드럽고 균일한 정면 조명 (한쪽 조명 금지)
   - 옷은 검정색으로 통일
   - 아름답고 개성 있는 세련된 패션 모델 인상
   - 10대는 나이에 맞는 단정한 모습
4. `IP모델 소스.png`에서는 배경·구도·조명만 참고합니다. 참조 이미지 속 인물의 얼굴은 복사하지 않습니다.
5. 다음 결과는 버리고 해당 프롬프트만 다시 생성합니다.
   - 여러 인물이 합성된 이미지
   - 미리보기·패널·격자·콜라주가 들어간 이미지
6. 5장 중 서로 닮은 얼굴이 있으면 해당 프롬프트를 수정해 대체 이미지를 새로 생성합니다.
7. 결과는 프롬프트와 이미지를 같은 번호로 짝지어 제시합니다.

> GPT에 넣는 고정 지침 전문은 `ip-generation/SKILL.md`에 있습니다.

### 실제 실행 화면

1. Claude에서 `/ip-register 20대 한국 여자`를 입력합니다.
2. Claude가 준비를 확인합니다. 작업 폴더 `IP 모델`이 없으면 새로 만들고, 생성관리 시트에서 해당 행을 찾습니다.
3. 크롬의 ChatGPT에서 `@ip generation 한국 20대 여자`가 자동으로 실행됩니다. 5장을 만드는 데 약 6분(캡처 기준 5분 57초)이 걸리고, 교체본이 있으면 더 많이 생성됩니다.

> ⚠️ **주의:** ChatGPT가 "`IP모델 소스.png`를 라이브러리에서 찾지 못해 프롬프트에 조건을 반영했다"고 답하는 경우가 있습니다. 그러면 구도·조명이 기존 모델과 달라질 수 있습니다. ChatGPT 라이브러리(또는 대화)에 `IP모델 소스.png`가 올라가 있는지 먼저 확인하세요.

## 6. 얼굴 중복 검수

### 비교 대상 (4곳 모두 확인)

1. 이번에 만든 이미지끼리
2. NAS `@등록완료` 전체 (`109명 이전` 포함)
3. NAS `등록 전\@모델소스` (`완료\` 포함, `제외\`는 빼고)
4. 작업 폴더에 이미 있는 얼굴 (`@제외`는 빼고)

### 판정 기준

| 체감 유사도 | 처리 |
|---|---|
| 70% 초과 | 같은 사람으로 보고 제외. 교체본이면 정면 사진 한 장만 남김 |
| 60~70% | 등록하고, 보고에 '닮음'으로 적음 |
| 60% 미만 | 등록 |

- 제외한 이미지는 지우지 않습니다. `@제외\`로 옮기고 파일명에 이유를 붙입니다.
- 유사도는 눈으로 보고 판단한 수치이며, 보고에도 그렇게 밝힙니다.

### 제외 파일명 예시 (NAS `등록 전\@모델소스\제외\` 실제 사례)

| 유형 | 예시 |
|---|---|
| 같은 묶음 내 교체본 | `…_06 (제외-01과 같은 얼굴 교체본).png` |
| 등록 모델의 재생성본 | `나이지리아_10대_남자_07 (제외-298 Chinedu와 같은 얼굴 재생성본).png` |
| 재검수에서 유사도 70% 초과 | `나이지리아_10대_남자_04 (제외-재검수 유사도 70%초과, 249 Chinedu와 비슷한 얼굴).png` |

- 이유에 **비교한 등록번호와 이름**을 꼭 적습니다. 그래야 나중에 다시 검토할 수 있습니다.
- `제외\등록취소_번호폴더`에는 등록을 취소한 번호 폴더를 모아 둡니다.

### 중복검수 비교표 (`@중복검수_비교표_No24.jpg`)

- 닮은 얼굴끼리 한 줄로 묶습니다. 예: `1. 동아시아 남`, `13. 유럽·남미 남`, `26. 나이지리아`
- **초록 테두리 = 유지**(등록), **빨간 테두리 = 제외**입니다.
- 사진마다 위에 `번호 이름 유지/제외`가 적혀 있어 한눈에 확인할 수 있습니다.
- 사람이 최종 확인할 때 이 비교표를 먼저 봅니다.

## 7. 보고 내용

- No별 흐름: 생성 장수 → 교체본 정리 → 중복 제외 → 등록 수
- 번호 ↔ 영문(한글) 이름 ↔ 키·몸무게 표
- 제외한 얼굴과 이유, 닮은 얼굴, 정면 사진이 없는 경우
- 등록관리 시트 검증 결과, 생성관리 기록, 폴더 위치, 한도 때문에 남은 No
